# QueQuest 0.4 · reusable behavior pass

## Главная идея

Функция появляется только после того, как игрок уже умеет обработать одну
очередь и сталкивается с повтором той же логики на двух линиях. `def` — не
новая тема урока, а способ перестать копировать уже понятное поведение.

## Сделано

- новая четвёртая смена `function` и награда `reward4`;
- две физические линии A/B с обычными и красными ящиками;
- настоящий Python `def route(batch)` + два вызова;
- один `DEF ROUTE()`-картридж в мире и две видимые связи к линиям;
- Python trace показывает линию, текущий ящик и решение IF;
- мгновенный visual pulse при сборке каждого фрагмента;
- `DEF / FUNCTION` добавлен в журнал навыков;
- сохранение/возобновление знает новые checkpoints;
- красные ящики остаются на месте на обеих линиях;
- после главы переход идёт в существующий локальный friends sandbox.

## Следующая логичная глава

Не вводить новую конструкцию ради программы курса. Следующая проблема должна
заставить игрока захотеть **состояние/словарь или событие**. Лучший кандидат —
Q-Bot и друзья, где один и тот же вход требует разной реакции в зависимости от
того, что система уже знает. Канонические характеры друзей не выдумывать без
авторского материала.
