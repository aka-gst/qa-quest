# QueQuest 1.0 — release pass

## Что завершено

QueQuest 1.0 доводит game-first кампанию до восьмой главы. После Friends → Vika → Virus игрок не попадает в экран «когда-нибудь будет автоматизация», а проходит полноценный автоматизационный цех.

### Глава 8 · Automation Foundry

1. Два заказа `FILE / TEXT / TABLE` сначала проходят руками через `READ → ROUTE → SAVE`.
2. Игрок собирает из тех же узлов автоматический pipeline.
3. Вход 2/s упирается в `ROUTE` 1/s: очередь растёт прямо на поле.
4. Ускорение источника и увеличение буфера не объявляются решением throughput; второй worker реально разгружает очередь.
5. После появления двух worker-ов возникает race на общем `ledger`.
6. `Lock` появляется как физически понятное решение общей записи.
7. Только после победы открывается эквивалент на Python с `asyncio.Queue`, `create_task`, `queue.join`, `gather` и `asyncio.Lock`.

### Визуальная грамматика

- данные — движущиеся карточки груза;
- очередь — физический накопитель между узлами;
- bottleneck — одновременно очередь + численный throughput;
- worker — отдельный работающий узел;
- race — конфликт двух worker-ов у общего ledger;
- lock — видимый протокол доступа, а не абстрактный термин.

### Эпилог

После `reward8` QueQuest считается завершённой аркой. Эпилог показывает три необязательных направления: QA Quest/тестовая лаборатория, Pythonio/реальные автоматизации и самостоятельное проектирование систем. Обязательной «главы 9 coming soon» нет.
