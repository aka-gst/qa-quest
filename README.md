# QueQuest

Игра о человеке, который умел управлять сложными системами, потерял всё и
собирает себя заново. Python здесь не предмет урока, а первый найденный способ
менять мир: сначала игрок таскает ящики сам, затем одной программой оживляет
роборуку и освобождает собственное время.

Это новый продукт с чистого старта. Старые маршруты, режимы и прогресс QA Quest
не загружаются. Новая игра хранит только безопасные контрольные точки в
`quequest.game.v1` и никогда не читает `qaquest.v2`.

## Что можно пройти сейчас

1. Сразу двигаться и использовать три разные силы против шести угроз.
2. Пережить потерю способностей.
3. Вручную перенести три ящика через склад.
4. Запустить настоящий CPython командой `print("WAKE")`.
5. Написать правило для роборуки и увидеть, как каждое событие Python становится
   одним физическим переносом в мире.
6. Столкнуться с красным ящиком, который нельзя обработать старым правилом.
7. Вернуться в гараж к первой оболочке Q-Bot и увидеть следующий горизонт:
   боты, агенты, собственный AI.

## Запуск локально

```bash
sh tools/fetch-pyodide.sh   # один раз, если vendor/pyodide ещё нет
python3 -m http.server 8765
```

Открыть <http://127.0.0.1:8765/>.

Управление:

- WASD или стрелки — движение;
- Shift — рывок;
- Q — импульс;
- E — щит;
- Space — взять, поставить или осмотреть;
- на телефоне — вести пальцем по миру и нажимать экранные действия.

Адреса `?тихо`, `?tiho` и `?quiet` запускают игру без создания `AudioContext`.

## Живой ролик «сам → автоматизация»

Если локальная игра открыта в Chrome с включённым CDP на порту 9223, одна
команда проходит склад настоящими нажатиями, запускает настоящий Python и
собирает непрерывный десятисекундный ролик без звука:

```bash
node tools/record-showcase.mjs
```

Результат: `showcase/quequest-manual-to-ai-10s.mp4`. Временные кадры остаются
в игнорируемом `trash/`, чтобы по ним можно было проверить начало, середину и
конец дубля.

## Устройство нового runtime

```text
index.html             единый игровой экран
styles.css             HUD, мобильная и горизонтальная раскладки
src/game/
  main.js              игровой цикл и оркестрация сцен
  model.js             чистое состояние, физические последствия, контрольные точки
  render.js            Canvas 2D: пролог, склад, рука, гараж
  input.js             клавиатура, указатель и touch
  machine.js           две настоящие Python-программы игрока
  events.js            белый список событий Python → мир
  audio.js             процедурная звуковая обратная связь
  save.js              изолированное сохранение новой игры
  telemetry.js         локальные замеры без сетевой отправки
src/runner.js           мост к изолированному Python worker
src/pyworker.js         Pyodide/CPython и ограниченная сериализация событий
```

Python работает в Web Worker, не имеет доступа к DOM и JavaScript. В основной
поток проходят только новые JSON-объекты вида
`{ type: "arm.move", boxId, targetId: "pallet-a" }`; неизвестные типы, поля,
ящики, цели и дубли отклоняются.

На localhost доступен `window.__QUEQUEST_DEBUG__`: снимок мира, локальные
временные события и замер FPS. Код игрока, stdout и тексты ошибок туда не
пишутся и никуда не отправляются.

## Проверка

```bash
node --test tools/game-*.test.mjs tools/python-unavailable.test.mjs
sh tools/selftest.sh
```

`tools/verify_content.py` относится к прежнему содержимому и пока запускается
отдельно как проверка сохранённого Python-движка, а не как критерий новой игры.

## Статус

Эта ветка — локальный исходник первого игрового среза. Она ещё не выложена на
боевой сайт. Реальный LLM, команда агентов, автономный магазин и финальный выбор
мира — дальнейшие главы, а не имитации внутри текущего среза.
