# QA Quest

Игровая браузерная лаборатория для повторения Python и изучения QA Automation / AI & LLM QA.

## Что уже есть в MVP

- 10 последовательных миссий: от переменных Python до LLM-evaluation;
- редактор кода, терминал, проверки и меняющаяся визуальная модель;
- XP, уровни, разблокировка миссий и сохранение прогресса в `localStorage`;
- подсказки, примеры и сочетание `Cmd/Ctrl + Enter` для запуска;
- адаптивный интерфейс без сборщика и внешних JS-зависимостей.

## Запуск

```bash
cd "/Users/gst/dev/QA Quest"
python3 -m http.server 4173
```

Открыть: <http://127.0.0.1:4173>

## Ограничение первой версии

Код проверяет детерминированный учебный движок: он анализирует решение и моделирует результат миссии, но пока не запускает произвольный Python. Следующий технический этап — безопасный Python runner (Pyodide локально в браузере либо изолированный backend), реальные pytest-тесты и редактор Monaco.
