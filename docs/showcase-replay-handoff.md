# B: воспроизводимая съёмка на настоящем движке

Источник: e7e1981; отдельный вход `showcase-replay.html`. Нормальный index/main/model/render/config не изменены. Это монтаж боя и склада, не обещание обычного первого входа. Не публиковать служебную страницу: владелец сайта снимает только canvas и выпускает ролик отдельно.

## Запуск и съёмка

Из корня рабочего дерева: `python3 -m http.server 8765 --bind 127.0.0.1` (сначала проверить, свободен ли порт).

Открыть `http://127.0.0.1:8765/showcase-replay.html?frame=0`.

После загрузки существует `window.__QUEQUEST_REPLAY__`: `pause()`, `seek(n)`, `fps=30`, `frameCount=411`, `cutFrame=120`, `width=1280`, `height=720`, `durationMs=13700`. `seek(n)` синхронно рисует настоящий снимок движка с фиксированным временем. Записывать все canvas-кадры 0…410 по порядку, не таймер воспроизведения: его скорость зависит от нагрузки. Полное окно браузера с кнопками не является кадром ролика.

После сохранения PNG как `frame-0000.png`…`frame-0410.png` команда упаковки:

`ffmpeg -framerate 30 -i frame-%04d.png -frames:v 411 -c:v libx264 -pix_fmt yuv420p -movflags +faststart -an quequest-replay.mp4`

Ожидается 1280×720, 411 кадров, 13.700 секунд, без аудио. Эта команда упаковки здесь не запускалась; PNG-последовательность/MP4 ещё не произведены. Снимок canvas по seek — обязанность съёмщика, не старого `tools/record-showcase.mjs` (он снимает декоративный manual).
