# QueQuest · референсы: что уже получено и как использовать

Приоритет не означает «книга лучше вообще». Это порядок полезности именно для QueQuest сейчас.

1. `game-feel-a-game-designer-guide-to-virtual-sens.pdf` — управление, отзывчивость, звук, polish, ощущение физического действия.
2. `Iskusstvo_Geymdizayna_Kniga_linz.pdf` / Jesse Schell — выбирать одну полную версию. Нужна для системного разбора мотивации, обучения, challenge/skill и опыта игрока.
3. `Scott_Rogers_-_Level_Up_-_The_Guide_to_Great_Vi.pdf` — уровни, управление, HUD, персонажи, темп и структура игровых эпизодов.
4. `Ромеро Маркос, Сьюэлл Бренден - Blueprints. Визуальный скриптинг игр в Unreal Engine 5...pdf` — не ради Unreal, а ради визуальной грамматики event graph: как показывать потоки, условия, события и связи без превращения их в учебник.
5. `Седер Н. - Python. Экспресс-курс ...pdf` — как контроль полноты и терминологии для новичка; использовать после game-design книг, а не как сценарий кампании.

Второй эшелон:

- `Робертс П. - Искусственный интеллект в компьютерных играх - 2024.pdf` — когда начнём делать Q-Bot/друзей игровыми агентами;
- книга по GUI из списка — для финального mobile/desktop UX;
- multiplayer-книги — только когда friends-defense действительно станет сетевым, не раньше.

LLM/RAG/LangChain/MCP книги из папки пока не нужны для первых глав QueQuest. Они пригодятся позднее для ступени агентов/LLM, но сейчас ухудшат фокус.


## Получено 19.09.2026

Получены и уже используются как дизайн-референсы: Game Feel, The Art of Game
Design, Level Up!, Blueprints UE5, Python. Экспресс-курс, Game AI Uncovered и
книга по параллельному Python. Копии книг **не входят** в релиз игры.

До реализации friends/Q-Bot глубоко Game AI не нужен. До поздней темы
асинхронных задач/агентов параллельный Python тоже не нужен. Новые книги сейчас
не приоритет: важнее плейтестить и реализовывать полученные принципы.
