## Сверка перед сдачей

- После трёх ящиков приходит начальник, торопит игрока и хлопает дверью.
- Бумажка с `print("wake")` и чип Python падают в разные стороны.
- Чип — отдельное доступное действие игрока, а не автоматический переход.
- Вставка чипа оживляет руку и только после неё открывает терминал.
- Ошибка в команде отвечает подсказкой; верная `print("wake")` запускает руку.
- `?showcase=chip` повторяет момент для съёмки без звука и без ручного ввода.
