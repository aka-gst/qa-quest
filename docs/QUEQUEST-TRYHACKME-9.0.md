# QueQuest 9.0 — что полезного взяли из TryHackMe

Исследование проводилось как референс **учебного геймдизайна**, а не как источник техник атак. QueQuest остаётся безопасной симуляцией собственных синтетических систем.

## Что у TryHackMe работает для нашей цели

1. **Browser-first hands-on.** Человек может начать практику без длинной установки окружения. QueQuest уже следует тому же принципу через локальные симуляторы и Pyodide/CPython.
2. **Learning paths → modules → rooms.** Большой предмет разбит на короткие практические пространства. Для QueQuest эквивалент — кампания → районы/лаборатории → конкретные системные истории.
3. **Walkthrough vs challenge.** Сначала guided practice, затем challenge, где знания нужно применить самому. Это стало главным изменением 9.0: DISCOVERY → MASTERY → DIRECT PATCH / BLACK BOX.
4. **Difficulty = amount of guidance.** Сложность не обязана означать больше HP/таймер. Она может означать меньше подсветки, меньше готовых путей, больше самостоятельного исследования.
5. **Hands-on вместо quiz.** Даже их рекомендации для публичных rooms просят не превращать практику в тест на запоминание. QueQuest сохраняет это как системное правило.
6. **Optional short missions.** Маленькие цели полезны против перегруза каталога. Позже для QueQuest можно сделать локальные “сменные цели”, но они не должны создавать FOMO.

## Что сознательно НЕ копируем

- ежедневный streak как угрозу потери прогресса;
- leaderboard как главный мотиватор одиночной кампании;
- требование повторно совершать “meaningful interaction” после того, как игрок уже доказал mastery;
- терминологический каталог вместо цельного мира;
- реальные offensive targets/credentials.

## Новое правило QueQuest 9.0

**Первый раз игрок обязан понять мир. Второй раз игра обязана уважать его знание.**

Новый паттерн: исследование → наблюдения → вмешательство → последствия → техническое имя → Python.

Освоенный паттерн: симптом → архитектурное решение **или сразу код**.

Полностью освоенная система: BLACK BOX → неизвестный symptom без подсветки → свободное расследование или direct code.

Это должно давать не ощущение “урок стал сложнее”, а ощущение “я стал сильнее”.
