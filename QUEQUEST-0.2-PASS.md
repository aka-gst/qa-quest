# QueQuest 0.2 · game-first pass

## Реализовано

- сохранён первый эпизод: 3 ручных ящика → начальник → дверь → чип → автодоставка без синтаксического барьера;
- вторая смена начинается с физически снятой кнопки машины;
- `print("wake")` заменяет потерянный сигнал запуска и исполняется настоящим CPython/Pyodide;
- слепая автоматизация доходит до красного груза и безопасно останавливается;
- отдельная задача `for + if` оставляет красные ящики и переносит обычные;
- терминал объясняет каждую строку через её наблюдаемое последствие в мире;
- дневник открывает `PRINT`, `FOR`, `IF`, затем ранний `Q-Bot 0.1`;
- сохранены local-first checkpoints `shift2`, `red2`, `condition`, `reward2`;
- Vika в future glimpse использует сохранённую реплику «А вот и ты», но текущая картинка явно считается концептом, а не финальным каноном;
- добавлен `docs/QUEQUEST-GAME-DESIGN-0.2.md` с разделением восстановленного канона и нового design proposal.

## Проверено

- `node --test tools/*.test.mjs` — 144/144;
- `sh tools/selftest.sh` — все negative controls краснеют как должны;
- `python3 tools/verify_content.py` — 154 задачи, 0 ошибок, 0 тривиальных;
- `node --check` для изменённых runtime-модулей — OK.

## Не считаю проверенным

- физический iPhone / mobile acceptance;
- shared account/backend;
- реальные друзья/PvP;
- финальный дизайн Вики и вируса;
- поздние главы `while/functions/friends-defense/Vika/virus` — это roadmap, не выдано за реализованное.
