# QueQuest 0.7 · Vika memory + virus finale

## Что закрыто

Первая сюжетная дуга **Friends → Vika → Virus** теперь проходима целиком в local-first runtime.

### Глава 6 · Вика

- не расширяет неподтверждённый канон: синее парящее лицо без тела + «А вот и ты»;
- три одинаковых входных сигнала `◎` требуют трёх разных действий только из-за памяти;
- физическая панель `seen / trusted` меняется на каждом успешном шаге;
- неверный выбор не отнимает прогресс и позволяет мгновенный retry;
- после 3/3 раскрывается эквивалент `dict/state`, а дневник получает `DICT / STATE`;
- checkpoints: `vika` и `reward6`.

### Глава 7 · вирус / финал

- финал не использует HP и не учит реальным атакам;
- четыре синтетических сбоя: неожиданный тип, пропуск, таймаут, неверный порядок;
- процесс визуально ломается и восстанавливается подходящим приёмом;
- каждый восстановленный случай попадает в видимый журнал;
- после 4/4 раскрывается `tests → try/except → log`;
- дневник получает `TRY / TEST / LOG`;
- checkpoints: `virus` и `reward7`.

### После финала

Старые «видения будущего» заменены на мост после QueQuest: автоматизация, поздняя лаборатория тестирования и Pythonio. Старый QA Quest не удалён.
